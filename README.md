# Emaki 絵巻

*The agentic development environment.*

[Website](https://emaki.lol) · [Docs](https://emaki.lol/docs/) · [Download](https://github.com/alkaline-software/emaki/releases/latest) · [Changelog](CHANGELOG.md)

IDEs are made for hand crafting. In agentic workflows the chat does most of the work, yet the editor still takes the middle of the screen and the chat gets a narrow pane at the edge. Emaki turns this around: the agent chat takes the main space, the sidebar groups your sessions under their projects, and the files, the outline and two terminals stay hidden until you need them.

Emaki works with Claude Code and Codex, on macOS, Windows and Linux. It keeps every session on your computer: Claude Code deletes its transcripts after 30 days, so Emaki copies each one, byte for byte, before anything else touches it.

## Get Started

1. [Download Emaki](https://github.com/alkaline-software/emaki/releases/latest) for your system.
2. Install [Claude Code](https://docs.claude.com/en/docs/claude-code) or [Codex](https://developers.openai.com/codex/cli). The Agents page (⌘E) walks you through it.
3. Optionally, install [Git](https://git-scm.com/downloads) and the [GitHub CLI](https://cli.github.com) to commit, branch and push from Emaki.

The [docs](https://emaki.lol/docs/) cover each part of the window, the settings and the keys.
